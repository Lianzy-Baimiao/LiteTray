# Windows 11 26H1 x64 验证

本轮只处理 x64，ARM64 不在范围内。按实际模块、接口和任务栏结构选择适配，不按 `28000` 构建号整体放行。

## 两种已分析的实现

| 样本 | 通知区域模块 | 当前证据 |
| --- | --- | --- |
| 28000.1 基础系统 | `Taskbar.View.dll` | 实验包单屏运行验收通过，已纳入 5.16.2 候选默认资料；最终默认包待复测 |
| 28000.3365 后续更新样本 | `SystemTray.dll` | 精确模块与静态接口；独立安装和运行验收待完成 |

两组均采用已有的 XAML 宿主来源和通知区域坐标实现，但模块身份、函数地址和虚表地址分别保存。基础版的宿主元素字段为 `+0x10`、宿主至子对象为 `+0x38`、子接口至 source 为 `+0x10`。实际 QueryInterface 和 GetIids 数据确认其子接口为 `ec97afd0-5c0d-581b-9508-074773c6f1e0`，没有从版本号或类名推断接口身份。

28000.1 的通知区域坐标来自 `TryGetChevronScreenRect` 和 `TryGetIconScreenRect` 使用的三参数、接管元素引用的入口。另一个拖放入口尚未完成接口审查，未选择该入口。解析器的有界数据流检查和精确函数字节核验不等于任意新实现都能通过。

## 隔离测试介质

以微软签名的 UUP 元数据为文件身份依据。UUP 查询服务仅用于定位下载地址；转换脚本从已核验的签名 CAB 重新提取 Professional CompDB，解析包身份、版本、路径、大小和哈希，未把第三方查询结果作为文件真实性证明。

签名元数据描述 amd64 Professional en-US `10.0.28000.1`、`br_release.28000.1.251103-1709`。90 条 canonical 包引用对应 89 个文件，总计 3,689,327,702 字节。所有文件完整 SHA-256 通过，转换结束后再次逐一核验。68 个 CAB 分别提取并捕获为引用映像，与原始 ESD/WIM 一起用于严格导出；缺失数据不会被跳过或由其他版本代替。

安装映像保留导出的系统内容；WinRE 启动映像另加隔离部署脚本。镜像在宿主机上通过文件工具组装，没有挂载系统分区或在宿主机执行 DISM。必需 HEVC 组件另外下载 2,648,215 字节，包签名和清单哈希通过，附带的离线许可证已提取；其安装结果以客体日志为准。可选商店应用没有整体下载，因此不能据此声称覆盖所有预装应用。

完整来源、转换和实验资料保存在本地 `local/compatibility-26h1/`；系统介质位于单独实验目录，不加入 Git 或发布包。基础映像的 Production 标签不能替代安装后的版本、有效期和运行检查。

安装后的只读检查确认 Professional 26H1、28000.1，系统安装状态为 `IMAGE_STATE_COMPLETE`。Client.Core、ShellExperienceHost、StartMenuExperienceHost 和 HEVC 2.4.13.0 均已注册。系统处于未激活通知状态；没有调整时间或绕过激活。

首轮检查未发现原生任务栏窗口，保留为失败结果，此时尚未执行 LiteTray。诊断确认长期运行的测试引导脚本由首次登录命令同步启动，阻塞了桌面初始化。让该脚本结束后，原生任务栏出现，同一 Explorer 的 PID、启动时间和会话保持不变。后台通道交接还遇到 PowerShell 未保留进程句柄导致退出码为空的问题，该失败保留，未将空值当作正常退出码；随后在客体内重新启动测试通道。

新只读基线 `sandbox-20261110-221955-2048afc0` 通过原有窗口归属和任务栏数量检查，并再次核验三个实际加载模块。这个结果仅确认测试环境就绪，不等于 LiteTray 接管、恢复或交互验收。首次登录命令与桌面显示的关系见 [Microsoft 文档](https://learn.microsoft.com/en-us/windows-hardware/customize/desktop/unattend/microsoft-windows-shell-setup-firstlogoncommands)。

## 当前提交与后续发布

本次提交将 28000.1 纳入默认资料，并注册三个模块的执行指纹；默认九组，显式实验构建十组。离线实际模块验证通过：三个原始映像、三份仅元数据变化的未知身份被正确识别，23 处节内容变更被拒绝。28000.3365 仍为实验资料且仅接受精确身份，不继承基础版的验收。

5.16.2 尚未发布。今天按用户要求提交后停止，最终默认二进制构建与虚拟机复测、兼容性页的具体运行记录、安装包和 GitHub Release 留待继续。上述实验包不能当作最终默认包的验收。26H1 的副屏、多屏变化、混合 DPI、托盘复制、滚轮音量和完整菜单/悬停矩阵均未覆盖；ARM64 不在本轮范围。

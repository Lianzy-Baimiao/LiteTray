## 21H2 主屏时钟

普通 Windows 11 Pro 21H2 `22000.318` 独立客体以 Medium 权限运行本次正式二进制，通过真实合并时间/日期文本的三帧更新、宽度 `240 → 320 → 320` DIP 和停止恢复；原生宽度恢复为 63 DIP。原 Explorer 保持运行，产品正常退出，测试工作进程随后确认不存在。独立审查核对 R12/R13 两轮当前 nonce 的 44 个归档条目、全部冻结包文件、原始控件文字和恢复字段。

详细运行编号、模块身份和范围见 [21H2 验证](compatibility-21h2.md)。此实现只支持主屏时钟；两行共用第一行样式，副屏、托盘和真实输入未在此次验收中测试。

## 自动检查与发布边界

默认和实验工作区分别 317 项通过、9 项显式忽略；Python 解析器 68 项通过，正式程序隔离 XAML 179 项通过，后台兼容报告导出和异常回调生命周期检查通过。[实现提交的 GitHub CI](https://github.com/Lianzy-Baimiao/LiteTray/actions/runs/42785570931) 完整通过。

# 5.5 UI 检查记录

## 问题与修复

- 时钟显示／时钟样式每次导航都重建整页，并逐项填充字体和字号下拉框。修复前本机隐藏窗口的切换中位耗时 133ms、最大 153ms；字体列表有 212 项。对下拉框批量填充、预分配存储，并保留两页未变化的原生控件。缓存按配置和窗口布局匹配，主题、尺寸、预设、草稿变化会失效，不会复用过期输入。
- 五页在最小窗口中因纵向间距过大超出内容区。重新安排时钟、样式、多屏托盘、天气、关于和常规设置，收紧分组留白。页面不再默认携带滚动条；只在实际内容溢出时启用。
- 大窗口日历额外将底部留白计入滚动范围，滚动条又挤压右侧内容。日历现在按完整视口尺寸布置，与日程／计时页一样不产生外层滚动条。
- 天气页标题控件与“启用天气”勾选框的矩形重叠，缩短标题区域以分开控件；密钥和 API Host 输入框增加用途提示。
- 两行时钟都选择 32 号时，预览文字高度 52px，原行高仅 35px。预览按同一比例缩放两行字体以保持字号比例，避免上下裁切；不修改保存到任务栏的字号。

## 可重复验证

```powershell
.\tools\Invoke-Cargo.ps1 -CargoArguments @('test','--bin','LiteTray','ui_audit','--locked','--','--test-threads=1','--nocapture')
.\tools\Invoke-Cargo.ps1 -CargoArguments @('test','--bin','LiteTray','settings_clock_navigation','--locked','--','--test-threads=1','--nocapture')
.\tools\Render-UI.ps1 -OutputDirectory local\ui55-audited-renders
```

测量完整绘制时，将窗口放在独立的非输入桌面中显示，再在每次导航后同步完成重绘；不切换桌面、不向用户桌面发送键鼠输入。加入绘制后的本机测试中位约 15–16ms、最大约 33–34ms；首次创建样式页约 82–98ms。仅页面状态切换耗时约 0.1–0.2ms，这个数值不代表完整显示延迟。

测试夹具更换 DPI 上下文时需要全新进程，避免其他原生 UI 测试遗留的进程级窗口／DPI 状态；隔离进程设 20 秒超时。未修改 Windows 缩放、颜色、网络或正在运行的第三方程序。真实输入桌面上的显示合成、其他 DPI 和第三方主题仍需相应环境验证；本记录不代表所有 Windows 环境均已验收。

本机证据位于 `local/ui55-*.log`、`local/settings-layout-perf-before.log`、`local/settings-navigation-profile.log`、`local/ui55-audited-renders/`。实际发布包使用 `local/Check-HiddenStartupPackage.ps1` 在独立配置与非输入桌面中检查首次打开、全页导航和绘制耗时。

## 配置导出

在本机执行 `tools/Export-WindhawkProfile.ps1`，成功生成 `local/windhawk-profile.json` 并用 PowerShell 重新解析。

核对结果：schemaVersion 为 1、Windows build 为 26300.9711、包含准确的两个模块 ID、时钟首行为 `%date%  %time%`、托盘模式为 `all`。

## 交互原型

通过 visualize 的 render.py 生成本地检查页面，用本机 Edge 的 headless 模式执行浏览器交互验证：

- JavaScript 语法检查通过，运行无 pageerror。
- 初始月份为 2026 年 11 月，显示 42 个日期格。
- 切换下月、返回今天、选择其他日期均更新显示。
- 点击时钟可以关闭/重新打开面板。
- 秒显示选项会更新时钟文本，显示器范围选项会更新状态。
- 天气详情可以展开，且明确标记为示例。
- 紧凑布局的日历/天气标签切换正确。
- 320 px 容器宽度下 scrollWidth 等于 clientWidth，没有横向溢出。
- 人工查看宽版和窄版截图，确认主要内容和控件可见。

本地检查文件位于忽略版本控制的 `local` 目录。浏览器原型仅用于确认布局和交互，不代表正式程序使用 WebView，也不构成原生程序性能测量。

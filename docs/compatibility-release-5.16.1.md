# LiteTray 5.16.1 兼容性补充验证

本轮继续按模块实现、接口与实际场景补充覆盖，不增加按 Windows 构建号放行的规则。默认仍为八组 x64 参考实现；后期 21H2 的独立接口契约有静态证据，但没有新增生产资料，见[接口契约说明](compatibility-child-contracts.md)。

## 已发布 5.16.0 的混合 DPI 验证

独立 Windows 11 Pro 25H2 `26200.8037` WHPX 客体使用现有只读系统盘上的新差分盘，两块真实虚拟显示器均为 `1024×768`。通过 Windows 设置将副屏从 100% 切换为 125%，再恢复 100%；使用各屏上的自有 PMv2 窗口读取实际 DPI，得到 `96/96 → 96/120 → 96/96`。没有直接写入私有缩放注册表，也没有发送伪造 DPI 消息。

同一后台 LiteTray 5.16.0 进程在缩放切换后自动恢复两屏的本轮唯一文字及 240 DIP 宽度，分别在约 6.9 秒、4.6 秒后的检查中确认；切换期间有原生时钟短暂显示，不代表文字连续保持。恢复原缩放后，设备、主副角色、屏幕矩形、工作区和 DPI 与原记录一致。应用正常退出，原生时钟结构恢复；退出后的两次读数间隔超过 75 秒，从 `18:52` 变为 `18:54`。这个结果证明两端读数之间有跨分钟更新，不证明连续逐帧绘制或每秒刷新。

运行编号 `sandbox-20261110-185055-d3671190`，nonce `a8519a76a40c4171a608f907bf1d0844`，归档 SHA-256 `9d8858f1b4f4dcb8e3fbe904b1dce804cf5c3b39d7ab685aa7807a4f797c14d9`。测试包清单 `40989be9ef3eafc6d528224f6f37e6638f930463478b6678c185a616bdad145a`；EXE、适配器和 popup DLL 与 [5.16.0 正式二进制](compatibility-release-5.16.0.md)相同。Explorer PID `1188`、启动时间 `2026-11-10T10:42:19.5808712Z`、会话 1 保持不变；应用 PID `4388` 正常退出码 0，工作进程 PID `2004` 随后确认不存在。

该轮没有注入点击，没有启用托盘复制；不覆盖物理 HDMI/DP/USB-C 插拔、其他比例、休眠、显卡驱动或其他 Windows 版本。兼容性页只将这次结果计入对应模块的混合 DPI 场景，保留其他场景各自的旧测试包和未测试状态。

本地当前运行材料位于 `local/compatibility-expansion-5.16/8037-mixed-dpi-r1-current/`；传输收据为 `8037-mixed-dpi-r1-collected.json`。冻结候选及后续正式包记录均按具体文件哈希分别保存。

## 5.16.1 最终二进制：混合缩放与日历点击

最初的 5.16.1 候选在同一客体中接收到了真实点击，日历也显示出来，但 10 秒内未取得前台焦点。该失败保留为 `sandbox-20261110-190212-c96c96b7`，归档 SHA-256 `e2cec51c735d6ef616364ad08ef62c6d941749e7abfca580477533ceecafaa71`，不计入输入通过记录。更早的辅助程序编译失败发生在应用启动和显示缩放前，也未计入产品验收。

修复在 Explorer 的真实输入回调中，完成宿主存活与会话/控件验证后，调用 `AllowSetForegroundWindow` 向已保留的确切宿主 PID 交接前台权限，再转发日历激活事件。仅鼠标与键盘日历动作走此路径，音量滚轮与静音不申请前台权限。权限交接采用 [Windows 公开 API](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-allowsetforegroundwindow)，没有修改系统前台锁定策略。

保持原始输入助手及严格判定不变，实际完成以下操作：

1. 两屏托管文字和宽度生效，通过 Windows 设置将副屏改为 125%，实读 DPI 为 `96/120`，两屏托管文字自动恢复。
2. 用最新 XAML 几何确定主屏时钟位置，四次真实 `SendInput` 左键操作依次打开、关闭、再打开、再关闭日历。两次打开均核对到当前应用拥有的 `LiteTray.Calendar.1` 窗口可见且处于前台，每次点击后两屏托管文字均存在。
3. 恢复原 `96/96` DPI，设备、主副角色、矩形、工作区及 DPI 完整回到基线，托管文字自动恢复。
4. 应用 PID `3924` 接到正常退出命令，退出码 0；工作进程 PID `7744` 确认退出。原生时钟字段恢复，两次检查间隔 `75.233612` 秒，时间从 `19:26` 变为 `19:28`。保持唤醒的辅助进程也正常结束。

Explorer 始终为 PID `1188`、启动时间 `2026-11-10T10:42:19.5808712Z`、会话 1。没有重启 Explorer、强制结束产品或改变宿主机显示设置。这次受控前后对比支持缺少前台权限交接这一原因；不保证其他软件、后续用户输入或所有桌面策略下均能取得焦点。

输入范围仅为混合缩放环境中的主屏左键开关日历；未验收副屏点击、键盘操作、通知区域点击、托盘复制、菜单、音量、物理插拔和休眠恢复。5.16.1 程序内历史目录保留的是已有具体包的验收，最终包此次结果由本文件记录，避免将重新编译后的文件冒充已测二进制。
